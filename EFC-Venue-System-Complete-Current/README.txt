RECOMMENDED LOCAL WORKFLOW
--------------------------
1. Keep this extracted folder as your venue-system master.
2. Edit local files, not only the Weebly copies.
3. Save and test.
4. Upload only the changed JavaScript file to Weebly.
5. Publish and hard-refresh.
6. Commit the change to GitHub.

The EPK Performance Highlights widget uses the Core files.
The complete venues.html page uses both Core and Page files.
