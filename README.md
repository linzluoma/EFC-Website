# Electric Flower Co. Website

This repository contains the source code, tools, and assets for the Electric Flower Co. website.

## Project Goals

- Convert the website from static HTML to a dynamic, data-driven website.
- Store all show information in a single master database.
- Automatically generate the Upcoming and Past schedule.
- Create reusable widgets for the homepage and EPK.
- Make future website updates quick and easy.
