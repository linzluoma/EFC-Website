Electric Flower Co. Venue Page
================================

CURRENT FILES
-------------
venue-map.js          Version 1.1
venue-history.js      Version 2.2
venue-page-embed.txt  Package Version 2.0

PURPOSE
-------
This package creates the complete Where We've Played page, including:

- headline statistics
- interactive Leaflet map
- synchronized search and filters
- expandable venue-history cards

REQUIRED HEADER ORDER
---------------------
<script src="/files/theme/shows-data.js"></script>
<script src="/files/theme/show-utils.js"></script>
<script src="/files/theme/venues-data.js"></script>
<script src="/files/theme/venue-utils.js"></script>
<script src="/files/theme/venue-widgets.js"></script>
<script src="/files/theme/venue-map.js"></script>
<script src="/files/theme/venue-history.js"></script>

INSTALLATION
------------
1. Upload venue-map.js and venue-history.js to Weebly theme assets.
2. Delete older Venue History or standalone map embeds from venues.html.
3. Paste all of venue-page-embed.txt into one Weebly Embed Code element.
4. Publish and hard-refresh with Ctrl+F5.

The embed includes Leaflet and the required responsive map height.
